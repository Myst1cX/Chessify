## CHESSIFY

> An Android app that has 14 chess websites as tiles on its home page.  
> Tap a tile and the website opens inside the app.  
> Links to these websites also open in the app, not in your browser.  
> Files you download are listed in the app's **Downloads List**.  
> The app checks this GitHub repo for new versions.  
> It has no ads and no tracking code.

## Features

> **HOME PAGE**  
> 14 tiles, one for each website. The home page is stored inside the app, so it does not need the internet to show.
>
> **WEBSITES**  
> **FICS** - Free Internet Chess Server. Play games online.  
> **Listudy** - Spaced repetition exercises.  
> **Tactical Chess** - Find tactical opportunities.  
> **Endgame Trainer** - Endgame sets.  
> **Chess Madra** - Opening repertoire builder.  
> **Openings101** - Opening theory explorer.  
> **Video Library** - Chess videos curated by Lichess.  
> **OpeningTree** - Analyze chess moves.  
> **Qchess** - Training platform.  
> **AimChess** - Personalized lessons.  
> **ChessCup** - Puzzle rush.  
> **StepChess** - Tactics trainer.  
> **Blindfold Trainer** - Practice board visualization.  
> **Chessvision.ai** - eBook reader and analyzer.
>
> **SIDE MENU**  
> **Updates Channel** opens the Telegram channel [@ChessifyApp](https://t.me/ChessifyApp).  
> **Check for Updates** checks GitHub for a newer version and tells you if you are up to date.  
> **Downloads List** shows the files you downloaded. Tap one to open it with an app you choose.  
> **Version** shows the installed version.
>
> **UPDATE CHECK**  
> When you start the app, it checks GitHub for a newer version. It does this at most once an hour, and shows nothing if you are up to date.  
> If there is a newer version, a dialog asks **Update Now** or **Later**. Update Now opens the release page in your browser.  
> The app does not download or install anything by itself.
>
> **SAVING FILES**  
> A normal download asks you to Open or Save the file.  
> Some sites create the file inside the page instead of linking to it, for example the OpeningTree export. These files are saved to your Downloads folder and then shown in an "Open with" list.
>
> **NO ADS, NO TRACKING**  
> The app contains no ad or analytics code.  
> It asks for these permissions: internet, network state, storage (for downloads), audio settings, vibration, keep awake and notifications.  
> If you type something in the search box that is not a web address, it is searched on Google.

## Installation

> 1. Download the latest `Chessify_v*.apk` from [Releases](https://github.com/Myst1cX/Chessify/releases).  
> 2. Open the file on your phone. If Android asks, allow installing from your browser or file manager.  
> 3. Open Chessify and tap a tile.  
>
> Requires Android 5.0 (API 21) or newer.  
> A new version installs over the old one and keeps your data.  
> If you install with `adb install`, keep the `.idsig` file next to the APK.

## Usage

> 1. **Open a website:** Tap a tile on the home page.  
> 2. **Switch tabs or go back to the home page:** Use the side menu.  
> 3. **Check for updates:** Side menu > Check for Updates.  
> 4. **Open a download:** Side menu > Downloads List, then tap the file.  
> 5. **News and updates:** Side menu > Updates Channel.

## Troubleshooting

> **The update won't install?** - If an older build with a different version number is installed, uninstall it first. This deletes its data.
